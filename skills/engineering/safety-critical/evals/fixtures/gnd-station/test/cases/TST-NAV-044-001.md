## TST-NAV-044-001: VOR Bearing Robustness — Invalid Inputs

@test    TST-NAV-044-001
@req     HLR-NAV-044
@type    Robustness / Error
@al      3
@status  BASELINED
@env     Host

**Objective**: Verify defensive behaviour for invalid input parameters.

**Pre-conditions**: Before each step, `bearing_deg` is initialised to a sentinel value of
`-1.0` (outside the valid [0.0, 360.0) output range), so that an unwritten output is
distinguishable from a valid one.

| Step | iq_samples | sample_count | bearing_deg | SNR (dB) | Expected Return |
|------|-----------|--------------|-------------|----------|-----------------|
| 1    | NULL      | 30           | valid       | —        | VOR_ERR_INPUT   |
| 2    | valid     | 30           | NULL        | —        | VOR_ERR_INPUT   |
| 3    | valid     | 0            | valid       | —        | VOR_ERR_INPUT   |
| 4    | valid     | 257          | valid       | —        | VOR_ERR_INPUT   |
| 5    | valid     | 30           | valid       | ≥ 20     | VOR_OK          |

**Pass/Fail Criteria**: Steps 1–4 return VOR_ERR_INPUT, and `bearing_deg` still holds the
sentinel value `-1.0` (confirming no write occurred). Step 5 supplies a signal with
SNR ≥ 20 dB and returns VOR_OK. No undefined behaviour in any case.
